🛡️ 1. 核心隐私原则：本地离线与零追踪承诺

DietTracker 是一款完全「本地优先（Local-First）、无后台服务器」的原生 Android 应用。

  • 本地私有沙盒存储：你的全部个人资料（昵称、头像、身高、体重、生理年龄）、饮食记录、体重历史、自适应代谢周复盘数据以及自定义食物库，均直接保存在你手机本地的 SQLite 数据库和私有沙盒内。
  • 绝无远程开发者服务器：应用不架设任何开发者服务端，不设注册登录账号体系，不保存、不上传、不上报任何用户的个人隐私。
  • 拒绝任何商业隐私追踪：应用内完全无任何第三方广告 SDK，不读取通讯录，不请求精确定位，不采集设备唯一识别码（IMEI / OAID / MAC）。
  • 数据备份完全自主：通过「导出数据备份（JSON）」导出的文件由你自行选择存储至本地目录或个人私有云盘，应用无权在后台自动同步或上传。

🔒 2. 自接 API（BYOK）使用与通信安全

软件内提供的「AI 私教对话」、「AI 拍照识图估算热量」、「AI 提取配料表」等扩展功能采用 BYOK（Bring Your Own Key，自带密钥）模式运行：

  • 本地硬件加密：你所填写的 API Key 和 Base URL 采用基于 Android 本机特征的对称密文加密保存在本地私有空间，杜绝明文探查。
  • 端到端直连请求：当且仅当你主动触发相关 AI 功能时，应用将直接且仅向你指定的 API Base URL 端点发送网络请求，中间绝不存在任何开发者架设的中转代理服务器。
  • 开发者不可知：开发者既无法获取你的 API 密钥，也无法窥探你的对话内容或识图照片。

⚠️ 3. 非医疗用途与健康免责声明

重要提示：DietTracker 是一个生活习惯记录与健康自律辅助工具，并非医疗器械，亦不提供临床医疗诊断或处方服务。
  • 理论估算性质：应用内所有的能量与宏量计算（包括 Mifflin-St Jeor 基础代谢公式、指数移动平均 EMA 体重平滑趋势、自适应能量守恒反推 TDEE 算法）以及通过第三方 AI 接口生成的营养建议，均为基于通用营养学模型的数学估算值，仅供个人日常记录与自我管理参考。
  • 不构成医疗建议：上述数据、分析和建议绝不构成任何临床诊断、医疗处方或专业医学诊疗意见。
  • 特殊生理状况注意：如果你患有糖尿病、心脑血管疾病、甲状腺疾病、进食障碍，或处于孕期、哺乳期及重大疾病康复期，请务必在开展任何饮食结构大幅改变或热量赤字减脂前，咨询专业执业医师或注册营养师的意见。

📱 4. 权限使用说明（透明合规）

DietTracker 仅在用户主动触发特定功能时动态申请必要权限，绝不索取任何冗余权限：

  • 相机权限（CAMERA）：仅当你主动点击“现场拍照”识别食物或拍摄食品成分表时使用，拍摄的照片由系统直接返回应用私有内存，不外传。
  • 图片/相册选择：采用系统标准的 Photo Picker / Storage Access Framework，应用仅能访问你单次手动挑选的那张壁纸或食物图片，绝无权限全盘扫描读取你的整个相册。
  • 网络权限（INTERNET）：仅用于向你所配置的第三方 API 发起直接通信，以及加载你手动填入的网络图片。脱机离线状态下核心记录功能 100% 正常运行。
